# 资产录入检查表

> 用于业务域、指标、规则、SQL 模板、Agent 或 Skill 发布前检查。

## 基本信息

- [ ] 已提供稳定 `asset_key` 和中文名称。
- [ ] 已关联唯一业务域和工作区。
- [ ] 已指定业务负责人、数据负责人和维护团队。
- [ ] 已说明当前版本、状态和变更原因。
- [ ] 已标明来源系统、文档或导入批次。

## 数据与口径

- [ ] 表、字段、指标和规则引用均可解析。
- [ ] 已说明时间语义、粒度、单位、币种和必需过滤。
- [ ] 已说明不适用范围、反例和已知数据限制。
- [ ] 已确认数据新鲜度、质量风险和敏感数据策略。
- [ ] 未把用户权限、密钥或敏感明细写入资产内容。

## Agent 与 Skill

- [ ] Agent 能力范围、表策略、指标引用和分析模板明确。
- [ ] Skill Front Matter 完整，触发条件和不适用条件明确。
- [ ] 没有用自然语言描述代替强制过滤、权限或口径规则。
- [ ] 没有承诺无依据因果归因或数值预测。

## 测试与发布

- [ ] 路由正例和反例通过。
- [ ] SQL 表、字段、分区和必需过滤测试通过。
- [ ] Evidence 和计算公式测试通过。
- [ ] 已评估对已发布 Agent、指标和报告的影响。
- [ ] 已完成审核，存在回滚或弃用方案。
