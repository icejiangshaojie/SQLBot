# 产品术语与总览

## 产品一句话定义

AI2BI 是面向企业内部业务人员的、**受权限和指标口径约束的自然语言数据分析工作台**。它不是通用聊天机器人，也不是任意 SQL 执行器。

用户通过自然语言提出问题，系统在可访问的业务域内完成口径识别、受控取数、确定性基础分析、业务解释和证据呈现。

## 核心对象

| 对象 | 定义 | 例子 |
| --- | --- | --- |
| 业务域 `Domain` | 有明确业务边界、负责人和资产范围的分析领域 | 对公存款、对公外汇、零售卡 |
| 数据资产 `Asset` | 可复用、可治理的业务知识或数据对象 | 表、字段、指标、规则、SQL 模板 |
| Agent | 一个业务域的分析治理单元，定义能力、允许资产和隔离边界 | 对公存款分析 Agent |
| Skill | Agent 内的具体场景知识包，描述触发条件、步骤和输出要求 | 存款余额趋势分析 |
| 指标 `Metric` | 可复用且有明确口径的业务数字 | 日均存款余额、结售汇金额 |
| 分析契约 `AnalysisContract` | 用户本次问题的已确认口径 | 指标、时间、客群、维度、过滤条件 |
| 分析计划 `AnalysisPlan` | 为回答问题而制定的受控查询和分析步骤 | 总额、日趋势、客户 Top N 三项查询 |
| 分析任务 `AnalysisTask` | 一次完整的可持久化分析工作单元 | 从提问到最终报告的全部过程 |
| Evidence Pack | 查询后汇总的数据、SQL、范围、来源和指标上下文 | SQL 结果与执行范围 |
| 分析事实 `AnalysisFacts` | 后端计算或 SQL 直接给出的结构化事实 | 日均、Top 5 占比、最高点 |
| QA | 对 SQL、结果、答案和证据进行的分层检查 | 表越权、无来源数字、口径缺失 |

## 两类信息必须分开

### 定义资产

定义资产是长期维护的业务知识，经过审核和版本管理后才可以被运行时引用：

- 业务域与术语
- 数据源、表、字段语义
- 指标及其口径
- 业务规则与强制过滤条件
- SQL 模板、血缘、数据质量规则
- Agent、Skill、测试用例

定义资产不应被聊天临时结果自动修改。

### 运行产物

运行产物记录一次分析真实发生了什么，用于复现、审计、追问和问题定位：

- 用户问题、会话和当前身份
- 路由决策、已解析的 Agent/Skill/资产版本
- 分析契约和分析计划
- SQL、参数、权限决策、执行时间和结果摘要
- Evidence Pack、分析事实、最终答案和 QA 结果
- 模型、Token、延迟、错误和审计日志

运行产物必须引用当时使用的定义资产版本，不能只保存资产当前版本。

## 一次可信分析的最低链路

```text
用户问题
  -> 权限与业务域判定
  -> 口径澄清和 AnalysisContract
  -> AnalysisPlan
  -> SQL 生成与执行前策略校验
  -> SQL 执行
  -> Evidence Pack
  -> 确定性分析引擎
  -> AnalysisFacts
  -> LLM 业务解释
  -> QA 与证据展示
```

没有通过 SQL 结果或确定性计算验证的内容，不得被包装为数据事实。
