## 二、域边界定义

### 2.1 该域包含

- **卡产品全生命周期**：开卡（虚拟卡/实体卡激活）、消费（PV 授权）、清算、换卡、销卡
- **卡消费指标**：消费金额、消费笔数、消费客户数、ATM 取现、MCC 商户分类
- **卡收入支出**：交换费收入、Visa 赞助费、DCC 收入、外汇利润、清算成本、返现成本、净收入
- **MPAU（Monthly Active User）**：月活用户成分结构（新客首刷/持续活跃/沉默回流/流失回流/存量首刷）
- **NTB 新户转化**：新开户客户 T+14/T+30 首刷率、三选一（Stockback/PowerDraw/券）选择率
- **回赠计划**：Stockback（最股励）、PowerDraw（百万劲抽）、食买玩、循环赚、现金回赠
- **商户合作活动**：7-11、麦当劳、演唱会等品牌合作活动的消费/参与/留存分析
- **KPI 监控**：YTD/MTD 达成率、周趋势、月度跟踪

### 2.2 该域不包含

| 不包含的内容 | 归属 / 说明 |
| ------------ | ----------- |
| 对公卡（Business Card） | 对公域；卡域仅覆盖零售客户 |
| 存款产品深度经营 | Deposit 域；卡域仅引用存款标签做客群分层 |
| 投资产品交易 | Invest 域；Stockback 仅涉及回赠成本，不含股票交易本身 |
| 贷款审批/提款 | Loan 域；卡域仅引用贷款标签做画像补充 |
| APP 行为漏斗 | APP 域；卡域只引用 APP 活跃标签 |
| 营销活动触达 | Marketing 域；卡域只分析活动期间的消费转化效果 |

### 2.3 与相邻域的边界

| 相邻域 | 划分依据 | 接口字段 / 接口表 |
| ------ | -------- | ---------------- |
| Deposit | 卡消费后的资金沉淀属于存款域；卡域只看消费行为 | `dws_cust_card_trans_sum_d` |
| Invest | Stockback 回赠成本属卡域；股票交易属投资域 | `dws_card_cust_trans_date_income_cost_d.stockback_reward_amt_hkd` |
| Customer | 客户画像标签做分层属客户域；卡域只取卡相关标签 | `dim_cust_basic_info_ext_d_aiview.cust_sub_type` |
| Loan | 贷款标签做画像补充；贷款余额和收入不在卡域 | `dim_card_ntb_tag_d.loan_apply_time` |

### 2.4 零售/对公判断规则（⚠️ Skill 路由层必读）

> 卡域是**零售业务**，所有表走 `zabank_dw` project。

| 信号词 / 表达 | 归属判断 | 处理 |
|-------------|---------|------|
| 信用卡、借记卡、刷卡、消费、MPAU、NTB、Stockback、百万劲抽、回赠、MCC、Visa | ✅ **零售卡域** | 路由到 `card` Skill |
| 对公卡、企业卡、Business Card、Corporate Card | ❌ **对公域** | 拒绝，提示切换对公场景 |
| 仅说"卡"无修饰词 | ❓ **待确认** | 追问是零售卡还是对公卡 |

## 五、数据隔离规则

| 规则 | 内容 |
|------|------|
| **Project** | `zabank_dw`（零售卡域） |
| **客户 ID** | `cust_no` / `user_id`（零售客户标识） |
| **_aiview 优先** | SQL 走 `xxx_aiview` 视图，运行时 hub-first fallback |
| **HK/MCV 必拆** | 结果必须按 `cust_sub_type`（HK客户/MCV客户）拆分展示 |
| **分区过滤** | 全量快照表 `pt = (SELECT MAX(pt) FROM ...)`；增量表 `pt BETWEEN` |
| **成功授权过滤** | 消费明细表过滤 `is_successful_auth = 1` |
| **ATM 排除** | NTB 首消排除 `trans_channel <> 'ATM'` |
